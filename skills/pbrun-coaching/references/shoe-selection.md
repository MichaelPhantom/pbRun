# 跑鞋选购决策（碳板为主，2026 国产款）

按跑者**体重 / 配速 / 目标距离**判是否上碳板 + 选哪双。原则先于具体型号。

## 是否买碳板（判断条件，满足大多→买）

- **体重偏轻**（<75kg）：碳板推进效率对轻量跑者更明显，不易压塌中底
- **力量储备够**：能跑 4:15/km 左右间歇 + 月跑量 150km+ → 跟腱/小腿可驾驭高堆叠板
- **目标配速在甜蜜区 4:30-4:50/km**：这是碳板收益最大区间（太慢无收益、太快驾驭不住）
- 力量不足或纯堆慢跑量 → 不必上，用无板训练鞋更稳

## 铁律

1. **碳板只用于比赛日 + 高强度课**（间歇/节奏/速度），别穿它慢跑 Z1——浪费中底 + 增加跟腱负荷。
2. 日常堆量继续用无板训练鞋 / 稳定慢跑鞋，可显著延长碳板寿命。
3. **中底寿命 ~500-700km**（PEBA/氮超临界），据此估换鞋周期。
4. **窄楦碳板 42 码常需上 42.5**；比赛鞋留 ~1cm 余量（长距离脚充血变胖）。
5. **赛前磨合**：新碳板至少穿 2-3 次、累计 20km+ 再上比赛。
6. **跟腱适应**：从"无板日常"切碳板速度课时，先用 50-60% 强度适应 1-2 周，防应力性反应。

## 升级路线（配速进阶）

- 现在 4:30-4:50 → C202 6代 / 飞电6C 足够吃满目标
- 破 10K 40 / 半马 1:30 之后 → 飞电6 Ultra 或 160X 最新款
- 不要提前买最旗舰厚板：那是给 3:30 以内半马准备的，现在买是浪费

## 非碳板日常鞋（堆量/慢跑，别淘汰）

- 耐磨训练：特步 两千公里系列
- 稳定慢跑/恢复：亚瑟士 GT2000 系列
- 竞训/节奏：鸿星尔克 绝尘4（全掌 TPU 稳定片 + 超临界炁，**非碳板**，定位竞训/减震）
